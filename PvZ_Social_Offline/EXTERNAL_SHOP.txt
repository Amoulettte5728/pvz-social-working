External shop replacement
==========================

The original shop skin is completely replaced by the user's standalone
itemShop.swf. The old shop_ui image folder and its image-driven shop skin
are removed from the game files.

itemShop.swf is loaded through the normal UIResourceManager/SwfManager
resource id "itemShop". ItemShopUI uses that loaded SWF as its actual shop
root; it does not build or load the old shop pictures.

The adapter only maps the user's existing instance names to the names the
original ItemShopUI logic expects. It does NOT change x/y/scale/rotation of
those objects.

User SWF mappings:
    shopBackground  -> mainBg
    prevButton      -> prevBt
    nextButton      -> nextBt
    backButton      -> backBt
    tab_commend_1   -> tabBtn100
    tab_points_1    -> tabBtn8
    tab_garden_1    -> tabBtn0
    tab_strengthen_1-> tabBtn1
    tab_house_1     -> tabBtn7
    tab_shop_1      -> tabBtn5
    tab_function_1  -> tabBtn6
    tab_decorate_1  -> tabBtn3
    moneyHeader     -> moneyBg
    gemsHeader      -> gemsBg
    itemSlot1..6    -> item1..6

Dynamic values (money, gems, points, page number, item text/images and
purchase logic) are added/updated by the original shop logic. The visual
skin and button positions remain those supplied by itemShop.swf.
