ADVENTURE DIFFICULTY FIX — 2026-10-02
====================================

Problem seen on 前院1-1:
- The level detail panel displayed the difficulty tabs, but selecting a normal
  Adventure difficulty produced the Error overlay.
- Normal Adventure could still be interpreted as a tutorial because the offline
  server was using sequential internal level ids (4, 5, 6, ...) as the public
  mission/resource ids.

Fix:
- Kept the existing sequential progression ids internally for backward-compatible
  saves.
- Added the real Adventure resource ids from conf/missions.json.
- Normal Adventure mission ids now follow resourceId*10+difficulty:
    前院1-1 = 110 easy, 111 normal, 112 hard
    前院1-2 = 120 easy, 121 normal, 122 hard
    ...
- I1007 now exposes the real resourceId/missionId and the three difficulty records
  from the supplied level data.
- I1008 accepts both old sequential ids and the real mission ids, resolves the
  selected difficulty, and returns that difficulty's cooldown/coin/XP data.
- I4002 accepts the same ids and records the internal progression level plus the
  selected difficulty so completing a hard/normal run still advances the correct
  Adventure level.
- Normal Adventure remains type=1, modeId=1, isTutorial=false.

Source data:
- conf/missions.json contains three difficulty records (easy/normal/hard) for
  each enabled Adventure level. No fourth Hell difficulty was invented because
  the supplied level data does not contain a fourth difficulty record.

The tutorial levels 1-3 retain their original tutorial modes and progression.
