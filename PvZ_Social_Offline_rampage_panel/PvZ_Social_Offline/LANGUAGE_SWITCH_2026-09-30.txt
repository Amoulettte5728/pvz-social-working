Language switch - work in progress (build 2026-09-30-level3-full-lang1)
====================================================================
WORKING NOW
- Launcher: new "Language / 语言 / 語言" selector under "Play as".
  It saves the choice in language.json. It applies the next time the game starts.
- Web pages (/play and /accounts): a language menu. Changing it reloads the game.
- Server: GET/POST /api/language. When a language other than 简体中文 is chosen,
  every game file that has a translated copy in lang/<code>/... is served
  instead of the original. Missing translations fall back to the original.
  Strings the server itself sends (building and level names) are translated
  with lang/<code>/server_text.json.

TRADITIONAL CHINESE (繁體中文) - generated, NOT READY TO USE
- lang/zh-TW/ has Traditional versions (OpenCC, Taiwan-standard characters)
  of Localization.xml, conf/PlantData.xml, conf/ZombieData.xml,
  GamePropItem_1_.xml, QuestList_1_.xml, FeedPost_1_.xml, conf_1_.xml and
  the server strings.
- PROBLEM: the game's text uses fonts embedded in the SWFs, which contain ONLY
  the characters the original Simplified text needed. Traditional characters
  that differ (歡 練 選 個 們 殭 屍 點 擊 ...) show as blanks.
- Still Simplified: swf/.../MissionList.xml (level names) and text inside SWFs.

ENGLISH - not started yet (the menu entry exists; untranslated files fall
back to Chinese).

Words painted into images (菜单, 跳过新手教程, building signs...) are artwork
and stay in Chinese.
